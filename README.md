# KeyTrack Pro Enterprise 4.24 — Landscape Card Mode

## Corrección principal
En celular horizontal se elimina completamente el comportamiento de tabla del inventario.

Ahora:
- No aparecen encabezados FOTO / ARTÍCULO / MARCA...
- Cada producto es una tarjeta independiente.
- Marca, FCC ID, SKU y OEM/PN son bloques separados.
- Vehículo y Ubicación tienen sus propias áreas.
- Stock queda visible a la derecha.
- Acciones quedan en una sola fila.
- La barra inferior se mantiene fija.
- El menú lateral sigue funcionando como drawer.

## Instalación
1. No requiere SQL.
2. Reemplaza todos los archivos del ZIP en GitHub.
3. Espera Vercel.
4. No desinstales KeyTrack Pro.
5. Cierra completamente la PWA y vuelve a abrirla.
