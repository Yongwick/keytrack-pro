# KeyTrack Pro

Aplicación estática de inventario lista para Vercel.

## Subir a GitHub desde el navegador
Sube estos archivos directamente a la raíz del repositorio:
- index.html
- vercel.json
- manifest.webmanifest
- icon.svg
- sw.js

Después importa el repositorio en Vercel y pulsa **Deploy**.

Los datos se guardan localmente en el dispositivo mediante localStorage.
