# KeyTrack Pro Enterprise 4.20 — Wide Stock + Vehicle Fix

## Correcciones

- En pantallas anchas y horizontal el stock vuelve a mostrarse arriba a la derecha.
- Se reserva una columna fija para la cantidad.
- Stock normal: verde.
- Stock bajo: amarillo con `⚠ Stock bajo`.
- Sin existencia: rojo con `⚠ Sin existencia`.
- Vehículo recibe más espacio horizontal.
- El texto de vehículo ya no se corta lateralmente.
- El título del producto ya no invade la zona de stock.
- Ubicación se mantiene compacta.
- Conserva todos los cambios de v4.19.

## Instalación

1. No requiere SQL.
2. Reemplaza todos los archivos en GitHub.
3. Espera Vercel.
4. No desinstales KeyTrack Pro.
5. Cierra completamente la PWA y vuelve a abrirla.
