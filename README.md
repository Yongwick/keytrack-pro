# KeyTrack Pro Enterprise 3.1

Mejora visual del inventario:
- Fotos 68×68.
- SKU/OEM/FCC legibles.
- Compatibilidad vehicular compacta.
- Indicadores de cantidad por color.
- Acciones compactas.
- Inventario bajo y sin existencia se pueden filtrar tocando las tarjetas.

Instalación:
1. Reemplaza `index.html` y `README.md` en GitHub.
2. No ejecutes SQL.
3. Espera Vercel y recarga con Ctrl+F5.
